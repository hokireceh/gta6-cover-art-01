An offline browser app that turns your photos and a caption into GTA 6-style multi-panel cover art — Vice City neon-sunset grade, crop and position per panel, exports 1080x1080, 1080x1350 and 1920x1080 PNGs. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
