Neon Panels turns your photos into GTA 6-style cover art: four slanted panels, bold gradient caption lettering and a sunset or neon grade, exported as a PNG in 1080 × 1080, 1080 × 1350 or 1920 × 1080. It runs offline in the browser — your photos never leave your machine.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
